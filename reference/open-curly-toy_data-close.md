# toy_dataset for reportr purposes

A 3x15 toy dataset that allows the user to familiarize themselves with
lin_out, log_out, and kick_out.

## Usage

``` r
toy_data
```

## Format

A data frame with 15 rows and 3 variables:

- x1:

  A numerical column that can operate as the sole predictor required for
  lin_out and log_out

- y1:

  A numerical column that can operate as a numerical response required
  for lin_out

- y2:

  A categorical column that can operate as a binary response required
  for log_out
